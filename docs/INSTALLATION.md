# Installation and Windows build

[← Back to the README](../README.md)

## Installing (users)

1. Download `NewtonFractals-Setup-X.Y.Z.exe` from the
   [latest release](https://github.com/ElliotGalaor/Newton_Fractals/releases/latest).
2. Run it. The installer is not code-signed, so Windows SmartScreen shows
   *"Windows protected your PC"*: click **More info**, then **Run anyway**.
3. Choose the language, the folder and an optional desktop shortcut, then **Install**.

| | |
|---|---|
| Requirements | Windows 10 or 11, 64-bit. The 3D page needs OpenGL 2 (any recent graphics driver). Nothing else: Python, Qt and the C++ engine are bundled. |
| Install location | Per user by default, no administrator rights: `%LOCALAPPDATA%\Programs\Newton Fractals`. The installer also offers an all-users install in `C:\Program Files`. |
| Shortcuts | Start menu (app, user manual, uninstaller), optional desktop shortcut. |
| User data | Last parameters, functions and results: `%LOCALAPPDATA%\NewtonFractals` (*Aide › Ouvrir le dossier des données*). PNG exports default to the *Pictures* folder. |
| Update | Run the newer installer over the old one; settings are kept. |
| Uninstall | *Settings › Apps › Installed apps › Newton Fractals › Uninstall*. User data is kept; delete `%LOCALAPPDATA%\NewtonFractals` to remove it. |
| Manual | French user manual installed with the app: `F1`, the *Aide* menu, or the Start menu. Source: [docs/manuel/index.html](manuel/index.html). |

Silent installation (standard [Inno Setup options](https://jrsoftware.org/ishelp/index.php?topic=setupcmdline)):

```powershell
NewtonFractals-Setup-1.1.0.exe /VERYSILENT /CURRENTUSER
NewtonFractals-Setup-1.1.0.exe /VERYSILENT /ALLUSERS          # as administrator
"%LOCALAPPDATA%\Programs\Newton Fractals\unins000.exe" /VERYSILENT
```

> **Smart App Control (Windows 11).** When it is on, Windows blocks unsigned programs
> without a *Run anyway* option. Use the release `.zip` with Python instead (see the
> README), or build the installer yourself as described below.

## Layout of the installed application

```
Newton Fractals\
  NewtonFractals.exe       the application (PyInstaller bootloader, no console)
  _internal\               embedded Python 3.12, PySide6 (Qt), pyqtgraph, PyOpenGL, numpy, app code
  moteur\moteur.exe        C++ engine (MinGW, OpenMP) and its DLLs (libgomp, libstdc++…)
  manuel\, images\         user manual and its screenshots
  unins000.exe             uninstaller
```

The interface finds the engine in `moteur\` next to `NewtonFractals.exe`
(`newton_calcul.trouver_executable`). When run from source, it still uses `main.exe` or the
Visual Studio build as before, and keeps its files next to the code.

## Building the installer (developers)

Requirements: Python 3.11+ with `requirements.txt` and `pyinstaller`, g++ with OpenMP
(MSYS2 UCRT64: `pacman -S mingw-w64-ucrt-x86_64-gcc`), and
[Inno Setup 6](https://jrsoftware.org/isinfo.php) for the installer itself.

```powershell
python -m pip install -r requirements.txt pyinstaller
python packaging/construire.py
```

The script:

1. compiles the engine with g++ (or takes `--moteur path\to\main.exe`) and collects the DLLs it
   imports, read from its PE import table;
2. runs PyInstaller with [packaging/NewtonFractals.spec](../packaging/NewtonFractals.spec)
   (one-folder build, unused Qt modules removed, version resource written from `VERSION`);
3. adds the engine, the manual and its screenshots: `dist\NewtonFractals\` is a portable copy of
   the app at this point;
4. compiles [packaging/installateur.iss](../packaging/installateur.iss) with Inno Setup into
   `dist\NewtonFractals-Setup-X.Y.Z.exe` (skipped with `--sans-installateur` or if Inno Setup is
   missing).

Check a build end to end, the way the release pipeline does:

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
dist\NewtonFractals\NewtonFractals.exe --auto-test rapport.json; Get-Content rapport.json
```

`--auto-test` opens every page, runs a Newton and a Mandelbrot computation with the bundled
engine, checks the 2D curves and that the 3D (OpenGL) modules load, writes a JSON report and
exits with code 0 if everything works.

The icon (`packaging/icone.ico`, `ConsoleApplication2/icone.png`) is generated by
`python packaging/generer_icone.py`: a Newton fractal of z³ − 1 in the colours of the interface.

## Releasing

1. Update `VERSION` in `ConsoleApplication2/NewtonFractalsDrawing.py`.
2. Merge to `main`, then push a matching tag: `git tag v1.1.0 && git push origin v1.1.0`.
3. The [Release workflow](../.github/workflows/release.yml) checks that the tag matches
   `VERSION`, builds and tests the installer (silent install, `--auto-test` of the installed
   app, uninstall) and publishes it with the source archive.
